# typewriting-speed

    | Q W F P G |----| J L U Y ; |
    | A R S T D |    | H N E I O |

repo with my typewriting speed log. required for statistics and keyboard design decisions.

`typewriting.yaml` is the ledger. dates are ISO-8601. `spm` is symbols per minute as logged; `wpm` only when the original note recorded it. `event`, `note`, `test`, `board`, `layout` appear only when the source named them.

latest: 2026-09-02 — 470 spm, 94 wpm. keyboard v2, no keycaps, 15s monkeytype.
